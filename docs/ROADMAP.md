# One hunt at a time

I got my own Bloodborne copy running on my M5 Max. The next job is to keep
busy fights smooth, then help more people play their own copy.

## Done: my Mac setup

- [x] Back up my own disc and matching update from my PS4.
- [x] Make bbport the only engine this launcher starts.
- [x] Pin and verify the Mac engine download.
- [x] Merge the base game and update while keeping the originals.
- [x] Add a read-only setup check, settings choices, and frame-log summaries.
- [x] Share a walkthrough and Codex/Claude prompts in plain words.
- [x] Add optional weapon-name and loading-label tools without sharing game data.

These are checks on my setup. They do not prove every Mac, firmware route,
or game region works. See [the tutorial](PS4-TO-MAC.md) for the console steps.

## Next: steady 60+ FPS in crowds, then 90+

- [ ] Repeat the Central Yharnam crowd route with the same quality and warm cache.
- [ ] Record build, settings, hardware, slow frames, stutter, and crashes.
- [ ] Check controls, sound, game speed, visuals, and save/load.
- [ ] Test the optional crash fix through longer play.
- [ ] Verify the CSR mod inside the game.
- [ ] Reach and repeat 90+ FPS during real play at a stated quality.

My baseline stays 1080p / 60 cap / perf 3. A cap, short peak, or empty scene
does not check those boxes. [My notes](../PERFORMANCE.md) keep the limits clear.

## Then: more computers

Test bbport's supported paths on other Macs and on Linux, and investigate
Windows support. The [Windows and Linux plan](WINDOWS-LINUX.md) is still a plan.

## Later: the browser

Local browser execution or streaming from a host? That still needs a small
proof and measurements for input delay, quality, storage, and speed.
There is no browser build yet. This box gets bigger when you open it.
