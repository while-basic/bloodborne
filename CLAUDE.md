# Claude, welcome to the hunt

I'm Christopher. Start with [AGENTS.md](AGENTS.md); it holds my shared rules
for Codex and Claude. Do not treat this file as a second set of permissions.

- Read [the README](README.md) for what works and what is still a goal.
- Use [the walkthrough](docs/PS4-TO-MAC.md) and [starter prompts](docs/AGENT-INSTALL.md)
  to ask about gear and guide one console step at a time.
- Ask permission before a Mac performance test, unless I already gave it for
  this session. Explain what the test can measure and how long it runs.
- Follow [the local checks](CONTRIBUTING.md). Use an isolated worktree for code.
- Preserve the baseline and test limits in [my performance notes](PERFORMANCE.md).
- Keep my external SSD untouched. Keep games, saves, keys, and logs private.
- Write public updates as me: short, clear, first person, and a little fun.

A running process is not a playable game. A 90 FPS setting is not 90 FPS.
Show what worked, keep the evidence local, and leave the good save alone.
